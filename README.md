# YZRS / や印工務店

**Turning ideas into things, and keeping the how and why for next time.**

YZRS is where I document the things I build, repair, and automate, including the parts, wiring, failures, decisions, and tools behind them.

I keep these records so I can use them again later, and I hope they’ll be useful to someone else too.

**Build / Repair / Automate / Document**

## How I document projects

The repositories here are not only code storage.

For the primary projects, I keep a public **Repository State** describing:

- what the repository is
- whether it is actively maintained
- what the repository is authoritative for
- what has actually been verified
- what remains outside the verification scope

The goal is to leave implementation, documentation, failures, decisions, and verification evidence in a form that can be reused later.
